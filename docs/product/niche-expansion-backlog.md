# Astra Niche Expansion Backlog

These niches are potential growth wedges after the main web/video → save → review loop is reliable. They are not P0 implementation commitments.

## Selection criteria

A niche is attractive when it has:

- frequent real English exposure;
- obvious pain from not understanding context;
- natural saving/review moments;
- willingness to pay for convenience;
- low need for technical configuration.

## Niche 1 — Chinese knowledge workers reading English technical content

Pain:

- English docs, blogs, release notes, AI papers, GitHub issues.
- Need accurate terminology and fast comprehension.

Astra angle:

- bilingual webpage reading;
- terminology consistency;
- save real phrases from docs;
- weekly digest of learned technical expressions.

Differentiator:

> Not just translate docs — remember the technical English you repeatedly meet.

## Niche 2 — YouTube learners watching English tutorials

Pain:

- Captions are fast, idiomatic, and hard to review later.
- Useful expressions disappear after the video ends.

Astra angle:

- supported-video transcript panel;
- timestamp-backed saves;
- review card jumps back to source;
- video learning recap.

Differentiator:

> Turn supported videos into timestamped review cards.

## Niche 3 — Students and exam learners doing intensive reading

Pain:

- Need sentence-level understanding and vocabulary retention.
- Too much manual Anki card creation.

Astra angle:

- sentence explain;
- cloze cards from saved sentences;
- source-backed review;
- mobile daily review habit.

Differentiator:

> Build review cards from what you actually read.

## Niche 4 — Professionals writing English replies

Pain:

- Need natural English for email, comments, LinkedIn, GitHub issues, Slack/Notion.
- Want to learn from corrections, not just copy output.

Astra angle:

- input box translation/polish;
- explain why the rewrite is better;
- Correction Card for repeated patterns.

Differentiator:

> Understand and remember better ways to express your own ideas.

## Niche 5 — Mobile spare-time review

Pain:

- Users save content on desktop but forget to review.
- Spare time happens on phone.

Astra angle:

- Today Review first screen;
- recent saved;
- source return;
- streak/reminder.

Differentiator:

> Web is for capture. Mobile is for habit.

## Niche 6 — Bilingual creator/share cards

Pain:

- Learners like sharing useful English expressions but current tools make generic flashcards.

Astra angle:

- shareable sentence card;
- source-safe snippet;
- Astra watermark;
- invite/referral later.

Differentiator:

> Share one useful expression from real content, not a generic word list.

## Recommended sequencing

1. Knowledge workers reading English webpages.
2. YouTube tutorial learners.
3. Mobile review habit.
4. Writing/Correction Cards.
5. Student intensive reading.
6. Share cards/referral.

Do not pursue multiple niches at once until the core loop metrics show retention.
