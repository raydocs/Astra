# How Astra handles AI automatically

Astra tries to choose the right AI behavior for the learning task so you do not need to manage providers or model settings during first use.

Typical defaults:

- Translate helps you understand page text quickly.
- Deep Read explains a sentence or passage in learner-friendly language.
- Save sends useful words or sentences into Review.
- Review keeps practice short and focused on learning.

Astra should not ask new users to choose an API provider or model before first success. Advanced or managed deployment settings may exist for operators, but learner-facing copy should describe outcomes: read, understand, save, and review.

Boundary: AI output can be wrong. For release claims, Astra needs human-scored quality evidence before making production-quality promises.
