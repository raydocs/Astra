# How to translate your first page

Astra is designed to work without provider, model, or API setup for the first page.

1. Open a normal article or page in your browser.
2. Open Astra from the extension button.
3. Choose the default translate or Deep Read action.
4. Read the translated sentence or explanation, then save useful words or sentences for Review.

If nothing appears, try a regular article page instead of a browser settings page, PDF viewer, login-only page, or site that blocks extension access.

Privacy note: support reports should include only metadata such as hostname, browser, feature surface, and error category by default. Do not paste private page text into a support message unless you intentionally choose to share it.
