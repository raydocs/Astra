# How to delete your data

Astra has repo-side foundations for local export/delete controls, source deletion choices, relay account deletion, and Cloudflare continuity-data lifecycle work. The exact available path depends on whether you are using local-only data, signed-in sync, or a deployed relay.

Self-serve local controls may include:

- export local learning data;
- delete saved vocabulary or reading sources;
- choose source-only deletion or source plus linked saved cards where the Library supports it;
- disable sync or digest inclusion for a source.

For account-level or cloud deletion, use the support/contact path for the current release until deployment receipts and full account/billing deletion orchestration are attached to the release evidence.

Do not claim complete self-serve cloud deletion until the target deployment has verified backend evidence.
