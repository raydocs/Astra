# How membership works

Current release evidence supports free public-beta wording only unless billing, entitlement, cancellation/refund, legal, and store evidence are attached for the target release.

What users can expect in the beta boundary:

- core learning value should be described as read, understand, save, and review;
- Trial / Pro / paid checkout claims must stay disabled or clearly marked as not launched;
- support and known limitations should explain what is available now;
- cancellation, refund, and paid entitlement behavior require production billing evidence before public claims.

Do not describe membership in terms of tokens, provider names, or model selection. Use learner outcomes and actual launched capabilities.
