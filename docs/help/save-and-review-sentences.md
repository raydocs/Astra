# How to save and review sentences

Astra's learning loop is simple:

1. Read real content.
2. Translate or explain a sentence you care about.
3. Save the word or sentence.
4. Review it later from the Vocabulary / Review surface.

Review uses a learner-facing three-choice model by default:

- Again
- Good
- Easy

The Library and Weekly Digest summarize saved and reviewed activity with counts, source titles/types, repeated confirmed vocabulary, and coarse topics. They should not expose raw page text or transcript text in telemetry by default.

If a saved item came from a source, use Library/Reading to return to the source when that route is available.
