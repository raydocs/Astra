# Astra Product Screenshot Shot List

Use this when capturing README, landing, store, or launch visuals. Screenshots should show Astra as a zero-config learning product, not a settings-heavy AI tool.

## Global rules

- Prefer light theme.
- Do not show provider/model/API/token/quota/relay controls.
- Do not show dev/operator diagnostics.
- Prefer the loop: understand → save → review.
- Use supported videos wording when video appears.
- Avoid implying all websites or all videos work.

## Shot 1 — Public landing / GitHub preview

Purpose: communicate product positioning quickly.

Must show:

- “Learn from the English you already read and watch” or equivalent.
- no API setup / zero-config promise.
- bilingual reading preview.
- saved expression or review preview.

Do not show:

- provider/model/settings console.
- unsupported platform claims.

Suggested size: 1280×800.

## Shot 2 — Webpage bilingual reading

Purpose: show Astra working on a real page.

Must show:

- original English and Chinese support side by side or in place.
- page remains readable.
- subtle Astra control surface if visible.

Optional:

- translation progress if polished.
- saved expression highlight.

## Shot 3 — Selection explain and save

Purpose: show one-click learning asset creation.

Must show:

- selected phrase/sentence.
- explain/translate action.
- save for review action.
- post-save feedback if possible.

Caption direction:

> Save useful expressions from the page you are already reading.

## Shot 4 — Supported video transcript / subtitle

Purpose: show video learning, not just subtitles.

Must show:

- supported video context.
- transcript or subtitle line.
- save moment/timestamp affordance.

Do not show:

- full transcript export as the hero action.
- universal all-video claims.

Caption direction:

> Save moments from supported videos with timestamp context.

## Shot 5 — Today Review

Purpose: show learning habit.

Must show:

- today card count or active card.
- Again / Good / Easy or equivalent.
- source context from page/video.

Caption direction:

> Review real expressions from pages and videos you actually used.

## Shot 6 — Library / Recently saved

Purpose: show learning history.

Must show:

- recently saved items.
- source grouping/context.
- today review entry.

Do not show:

- complex folders or admin tables.

## Shot 7 — Mobile companion

Purpose: show mobile as habit layer.

Must show:

- today review.
- recent saved.
- streak/reminder if polished.
- source return if available.

Caption direction:

> Review during spare moments on your phone.

## Capture checklist

Before approving a screenshot:

- [ ] It supports the zero-config promise.
- [ ] It avoids implementation vocabulary.
- [ ] It shows learning progress, not just translation.
- [ ] It matches current product behavior.
- [ ] It is not over-cropped or too dense.
