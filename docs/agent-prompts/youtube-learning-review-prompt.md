# YouTube Learning Review Prompt

```text
Review Astra's supported-video learning experience.

Do not review it as a generic subtitle feature. Review whether it creates source-backed learning moments.

Check:
1. Does UI/copy say supported videos or best-effort, not all videos?
2. Are captions/transcript readable and not disruptive?
3. Can a user save a subtitle/transcript line without configuration?
4. Does the saved item include video title/source URL/timestamp?
5. Does Review show video context and allow return to source if supported?
6. Does no-caption fallback give a useful next action?
7. Is full transcript/SRT export absent from the default path?
8. Are errors ordinary-user friendly?

Return blockers, non-blocking UX improvements, and verification commands.
```
