# Astra Copy Review Prompt

```text
Review Astra copy for ordinary-user clarity.

Product direction:
Astra is a zero-config AI language-learning assistant. Users should not configure provider, model, API key, token, quota, or relay. Astra helps users understand webpages and supported videos, save expressions, and review later.

Flag copy that:
- exposes implementation terms: provider, model, API key, token, quota, relay, OpenRouter, OpenAI, Gemini;
- overclaims: all websites, all videos, every YouTube video, unlimited, no uploads, local-only;
- gives no next action after failure;
- sounds like a developer dashboard instead of a learning companion.

Rewrite flagged copy using calm, ordinary language in English and Chinese where appropriate.

Preferred vocabulary:
- Auto / 自动
- Faster / 快速理解
- Balanced / 精准阅读
- Study mode / 学习模式
- Save for review / 保存到复习
- Today Review / 今日复习
- supported videos / 受支持视频
- no unnecessary uploads / 默认不上传不必要内容
```
