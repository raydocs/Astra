# Mobile Habit Review Prompt

```text
Review Astra mobile as a habit companion, not as a browser-extension replacement.

Product rule:
Web/extension is for capture. Mobile is for review habit.

Check:
1. Does the first screen prioritize Today Review?
2. Are due cards ordered by SRS/due state, not simple recency?
3. Are recent saved items visible?
4. Do video/page source links preserve context?
5. Are streak/reminder mechanics light and motivating?
6. Does mobile avoid claiming live third-party webpage injection?
7. Does copy avoid provider/model/API/token/quota/relay?
8. Can a user complete a short review session in spare time?

Return product blockers, UX polish, and tests to run.
```
