Astra iOS Bridge Host

Thin host only: launch/open/handoff for Safari extension bootstrap.

  1. Install AstraShell and enable the Safari extension in iOS Settings.
  2. Open Safari, then open Astra popup or onboarding.
  3. Use Open in Astra App to trigger handoff via astra-shell://bootstrap.
  4. Return to Safari and continue reading with extension features.
