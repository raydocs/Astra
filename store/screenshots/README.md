# Chrome Web Store Screenshots

The Chrome Web Store requires 1-5 screenshots (1280x800 or 640x400 recommended).

Place the following screenshots in this directory after manual capture from a running extension:

1. **01-page-translation.png** -- Full-page bilingual translation on a real English article, showing side-by-side original and translated text.

2. **02-selection-toolbar.png** -- Selection toolbar in action: user has selected text, toolbar visible with Translate, Explain, and Save buttons, translation result shown.

3. **03-pdf-reader.png** -- PDF reader with inline translation, demonstrating bilingual reading of a PDF document.

4. **04-vocabulary-flashcard.png** -- Vocabulary notebook or flashcard review screen, showing spaced repetition in action.

5. **05-settings-page.png** -- Options/Settings page showing provider configuration, target language selection, and translation preferences.

## Capture tips

- Use a clean browser profile (no other extensions visible).
- Set the window to exactly 1280x800 before capturing.
- Use real, representative content (e.g., a Wikipedia article, a news site).
- Ensure the Astra UI elements (toolbar, translation overlay) are clearly visible.
- Avoid any personal or sensitive information in the screenshots.
